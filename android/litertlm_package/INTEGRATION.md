## Requirements

-   Android Gradle plugin 8.8 or newer.
-   Kotlin 2.3 or newer (the Kotlin Gradle plugin).
-   `minSdk` 31 or higher.
-   `arm64-v8a` ABI (`abiFilters`, step 3): the LiteRT-LM and Google Tensor NPU
    native libraries target 64-bit ARM (`arm64-v8a`).
-   The Google Tensor NPU itself is used only on Android 16 (API 36) or newer
    with NPU support (`Tensor G5` on Pixel 10, `Tensor G6` on Pixel 11); other
    devices fall back to `Backend.CPU()`.

## Steps

1.  **Copy the loader:** copy `kotlin/TensorLmLoader.kt` into your sources and
    set its `package` line (now `com.yunha.remy`) to where you put it.
2.  **Model files (sideload):**    Keep the `.litertlm` files in `models/` on your computer and push the build matching the attached Pixel's SoC (`Tensor_G5` or `Tensor_G6`) after installing the app (step 6 / `install_and_verify.py` automates this).

3.  **`app/build.gradle.kts`:**

    ```kotlin
    android {
      defaultConfig {
        minSdk = 31 // or higher
        ndk { abiFilters.add("arm64-v8a") }
      }
      // LiteRT-LM and Google Tensor dispatch find native libraries in
      // context.applicationInfo.nativeLibraryDir, so extract them at install time.
      packaging { jniLibs { useLegacyPackaging = true } }
      androidResources { noCompress += listOf("litertlm", "tflite") }
    }

    dependencies {
      implementation("com.google.ai.edge.litertlm:litertlm-android:0.18.0")
      implementation("com.google.ai.edge.litert:litert-npu-runtime-google-tensor:2.3.0")
    }
    ```

4.  **`app/src/main/AndroidManifest.xml`** (inside
    `<application>`):

    ```xml
    <uses-native-library android:name="libedgetpu_litert.so" android:required="false" />
    <uses-native-library android:name="libedgetpu_util.so" android:required="false" />
    <uses-native-library android:name="libvndksupport.so" android:required="false" />
    <uses-native-library android:name="libOpenCL.so" android:required="false" />
    ```

5.  **Use the model:**

    ```kotlin
       // In a coroutine (Dispatchers.IO):
   val loaded = TensorLmLoader.load(context)
   val conversation = loaded.createConversation(systemInstruction = "You are a helpful assistant.")
   loaded.sendMessageAsync(conversation, "Hello!").collect { message ->
     print(message.toString())
   }
   conversation.close()
   loaded.close()
    ```

```bash
adb logcat -s LiteRtTensor
```

-   When using `sideload` delivery, install and launch the app once (or let
    `install_and_verify.py` do it) so Android creates
    `/sdcard/Android/data/<your.application.id>/files/litertlm/` with app
    ownership, and `TensorLmLoader.kt` sets `cacheDir` to `context.cacheDir` so
    NPU compilation cache files never fail with `Permission denied`.
-   The log line reads `LITERT_TENSOR_RESULT {"path":"npu","kind":"litertlm",
    ...}` when the `.litertlm` bundle runs on the Pixel TPU. `"path":"cpu"`
    comes with an `npu_error` saying why.

## If something fails

Symptom                                                                                    | Fix
------------------------------------------------------------------------------------------ | ---
`IllegalStateException: LiteRT-LM model '...' not found`                                   | Push the `.litertlm` file matching the phone's SoC (`Tensor_G5` or `Tensor_G6`) with the `adb push` command above, or pass `--litertlm-package` to `install_and_verify.py`.
`"path":"cpu"` with `dlopen failed: library "libLiteRtDispatch_GoogleTensor.so" not found` | Check `useLegacyPackaging = true` and `com.google.ai.edge.litert:litert-npu-runtime-google-tensor:2.3.0` in `dependencies`.
`"path":"cpu"` with `libedgetpu_litert.so` error                                           | Add the `<uses-native-library>` lines in step 4 inside `<application>` in `AndroidManifest.xml`.
Native crash when sending an image to a text-only LLM                                      | Only pass `imageBytes` when the `.litertlm` bundle includes a vision encoder (`modalities` includes `vision`). `TensorLmLoader.kt` automatically ignores `imageBytes` on text-only bundles.
